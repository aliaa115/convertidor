# Hooks

## Estado actual

Hoy el proyecto no tiene una carpeta dedicada a hooks custom ni hooks reutilizables propios documentables como modulo independiente.

## Hooks usados dentro del codigo

- `useActionState`
- `useFormStatus`
- `useTheme`
- `useEffect`
- `useState`
- `useId`

## Recomendacion para el futuro

Si aparecen hooks propios, documentarlos aqui con un archivo por hook:

- `use-auth-user.md`
- `use-breakpoint.md`
- `use-local-storage-state.md`

Por ahora esta carpeta funciona como referencia del estado actual del proyecto.
